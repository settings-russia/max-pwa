# PWA «МАКС — вход в веб-версию»

PWA-обёртка для старого Android 5: открывает веб-версию мессенджера МАКС
(`https://web.max.ru`) в отдельной вкладке и позволяет установить точку входа
на главный экран как обычное приложение.

## Состав

| Файл | Назначение |
|------|-----------|
| `index.html` | Точка входа (ES5, максимально совместима со старыми браузерами). Кнопка открывает `web.max.ru`; если страница запущена внутри мини-приложения МАКС — использует `window.WebApp.openLink`. |
| `manifest.json` | Web App Manifest для установки на главный экран в standalone-режиме. |
| `sw.js` | Service Worker: кэширует статику PWA (offline fallback для самой страницы). Чужие ресурсы (`web.max.ru`) не кэширует. |
| `icons/icon-192.png`, `icons/icon-512.png` | Иконки для манифеста и главного экрана. |

> **Почему не iframe?** Статический сайт на GitHub Pages не может открыть `web.max.ru`
> внутри своей страницы — кросс-доменный iframe блокируется политикой безопасности
> (`X-Frame-Options`). Поэтому PWA честно открывает веб-версию в отдельной вкладке/окне.

## Как разместить на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите все файлы из этой папки в корень репозитория.
3. Репозиторий → **Settings → Pages** → **Set up a project site** → **Deploy from a branch** →
   выберите `main` и `/ (root)` → **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<пользователь>.github.io/<репозиторий>/`.
5. Откройте этот адрес на телефоне Android 5 и добавьте на главный экран (Chrome: меню ⋮ →
   «Добавить на главный экран» / «Установить приложение»).

Адрес в конфигурации не меняется: `scope: "./"` и относительные пути в `start_url`
работают из любой подпапки на GitHub Pages.

## Ограничения Android 5

- **Обновлённый Chrome** (≥ ~50 версии, что реально на Android 5 при последнем доступном
  Chromium ~81): Service Worker, манифест и `beforeinstallprompt` работают — PWA
  устанавливается полноценно.
- **Дефолтный старый WebView** (Chromium 37–40): Service Worker может не работать.
  Страница останется рабочей как обычная веб-страница (откроется вкладка `web.max.ru`),
  а установка — через штатное «Добавить на главный экран» браузера без фуллскрина.
  Это и есть причина, почему обёртка написана на ES5 и не полагается на современные API.

## Вход в веб-версию МАКС

- На ПК или в браузере телефона откройте `web.max.ru`.
- В приложении МАКС: **Настройки → Устройства → «Войти по QR-коду»** → отсканируйте код.

## Примечание по мини-приложению МАКС (необязательно)

Код поддерживает работу внутри мини-приложения МАКС: если подключить Bridge
(`<script src="https://st.max.ru/js/max-web-app.js">`), кнопка будет вызывать
`window.WebApp.openLink(web.max.ru)`. Для обычного использования на GitHub Pages это
не требуется.
